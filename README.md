# Bible Verse Memory

A simple phone app for memorizing scripture. Pick verses from a Bible-style book list, then press Play: it says the reference and reads the verses (ESV), over and over.

- **Repeat one verse** or **Go through all** your verses.
- Uses the ESV API. Paste your own free key from api.esv.org into Settings; it is stored only on your phone and never in this repository.
